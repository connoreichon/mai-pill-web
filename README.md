# Mai-Pill · web de descarga

La página desde la que se descarga Mai-Pill para Android.

**Esto es contenido generado, no código fuente.** Se produce con
`scripts/build-download-site.mjs` en el repositorio de la aplicación y se copia
aquí tal cual. Editar estos archivos a mano funciona hasta la siguiente
regeneración, que los sobreescribe; los cambios de verdad se hacen en el script.

## Cómo se publica

Cloudflare Pages conectado a este repositorio, **sin comando de compilación**:
son un HTML y unas imágenes, no hay nada que construir.

- Build command: *(vacío)*
- Build output directory: `/`

## El APK no está aquí

Vive como adjunto de una Release en `mai-pill-descargas`, y la página lo enlaza.
Cloudflare Pages no sirve archivos de más de 25 MB y un APK pesa bastante más.
